NEXORA — YOUR FIRST PREVIEW

WHAT TO DO (BEGINNER FRIENDLY)
1. Download NEXORA-preview.zip.
2. Extract / unzip it on your computer or phone.
3. Open the extracted folder. You should see index.html, manifest.json, sw.js and other files.
4. To publish it: visit https://app.netlify.com/drop and upload the extracted nexora-preview folder (not just index.html).
5. Netlify will give you a website link. Save that link.

INSTALL ON YOUR DEVICES
- iPhone/iPad: open the HTTPS website in Safari > Share > Add to Home Screen.
- Android: open in Chrome > menu > Install app / Add to Home Screen.
- Windows: open in Edge or Chrome > app/install icon in the address bar or browser menu.

WHAT YOU CAN PERSONALIZE
Open the ☰ menu: profile/display name, light/dark/system theme, five pastel colour palettes, text size, animal mascot, animations, compact layout, AI tone, backup preference, account and data export.
Creator credit: Shiva Verma.

IMPORTANT — WHAT IS AND IS NOT CONNECTED YET
This is a front-end prototype. Tasks, subjects, settings and journal are saved locally in this browser. Use Export my data to make a local backup.

Email / Google / Apple login buttons are placeholders until Supabase is configured. AI replies are demo-only, not a connected intelligent AI service. Daily backup time is saved as a preference only; it will not run in the cloud until secure authentication, storage and a server-side scheduler are configured. Do not enter real private information into this demo until cloud security is configured.

No paid plan, payment screen or premium lock is included. The future ₹20 idea is intentionally postponed.

NEXT SETUP (WHEN YOU ARE READY)
A free-tier Supabase project can provide real accounts and private cloud data. AI needs a server-side function and an AI provider; keep secret API keys on the server, never in index.html. Scheduled cloud backups need a backend scheduler because a browser cannot reliably run a backup while the app is closed.
