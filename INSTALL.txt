NEXORA CONSOLIDATED UI UPDATE
Release: 2026-11-21
Target: shivaverma17007-collab/nexora / testing branch

FILES
- nexora-update.js: the new UI and feature integration layer.
- ADD-TO-INDEX.txt: the one-line script include that loads this update.

INSTALLATION
1. Add nexora-update.js to the repository root, in the same folder as index.html.
2. Open testing/index.html.
3. Go to the very bottom. Find the existing final </script> that closes the current NEXORA application code.
4. Immediately AFTER that </script> and BEFORE </body>, add the one line shown in ADD-TO-INDEX.txt.
5. Save the changes to the testing branch. Test the branch preview before deploying to the live branch.

WHAT THIS UPDATE ADDS
- Refreshed NEXORA app styling and redesigned Home dashboard.
- Top-left hamburger and top-right profile shortcut.
- Persistent bottom quick-action navigation.
- Long-press Home cards to rearrange and save their order; Hydration can be hidden and restored by holding its controls.
- Daily Discipline Champion banner on Home when a champion record exists.
- My Trackers workspace, tracker duration (ongoing or end date), Standard/Sprint/Freestyle mode, and tasks inside each tracker.
- Legacy tasks stay preserved and appear under Unassigned tasks; no existing task data is deleted.
- The original Discipline concept remains, with a guided 14 + 10 + 7 day path, a struggle/habit prompt, daily check-ins, and Phase 3 stop/start reflection.
- Dedicated Profile page with display name, username, bio, profile privacy and HTTPS avatar URL controls.
- Community discovery, follow/unfollow requests, request approval/rejection, notifications.
- Dedicated Posts page with create, edit, delete and likes.
- Public App Reviews page, using the existing four review categories and existing RLS rules.
- Owner-only console: requires the fixed owner UUID AND a successful server-side nexora_is_admin() RPC check.
- Daily / weekly / all-time leaderboard page and Daily Champion card using existing backend functions/tables.
- Meditation page with 5/10/custom-minute timer, Hindi text guidance, current streak, post-session calmness rating and local session history. Existing ambient sounds remain in Mind Refresh; this update does not claim to provide recorded guided audio.
- Bilingual first-open release notice with a "Don't show future notices again" option.
- Google and email sign-in remain; Apple and phone options are hidden. Forgot-password requests are throttled for one minute in the UI.
- Quiz/PYQ, live Current Affairs and AI features are clearly marked Coming Soon until their secure backend services are ready.

SAFETY / DATA
- This is an additive frontend layer. It does not run SQL, deploy Edge Functions, or change GitHub/Supabase on its own.
- It does not contain a service-role key or create an Owner/Admin account.
- Owner access is checked by the existing nexora_is_admin() backend function; hiding the button is not the security boundary.
- Posts, likes, follow actions, requests, notifications and reviews use the existing Supabase tables/functions and remain subject to their RLS/security policies.
- Tracker, tracker-task, Discipline Journey and Meditation data remain in the existing local NEXORA state and follow the current explicit cloud-backup choice. No automatic backup preference is enabled here.
- Profile photo input accepts HTTPS URLs only; this patch does not create a Storage bucket or upload image files.
- If an existing RPC argument name differs, the code tries known argument-key variants and shows an error instead of pretending the action succeeded.

TESTING STATUS
- JavaScript syntax checked with Node.js (node --check).
- Not yet end-to-end tested against the live Supabase project or Cloudflare preview. Test the testing branch before release.
